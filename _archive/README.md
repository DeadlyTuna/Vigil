# Archived files

`other-ui-attempt/` holds a first-draft dashboard (page, layout, styles and 15 components) that appeared in this
folder while the main build session was paused. It was written against a guessed version of the simulator API
(e.g. `useSim` from `lib/sim/simulator`, `LogEntry.timestamp`) that does not match the real engine, so the site
returned HTTP 500. It is kept here untouched, excluded from type-checking and linting, and is not used by the app.
